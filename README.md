# Control y Monitoreo sobre Red CAN Bus mediante Bluetooth

Este proyecto consiste en la implementación y demostración de un sistema de control y monitoreo de iluminación y seguridad vehicular simulado en maqueta, utilizando comunicación en **red CAN Bus** y control inalámbrico mediante **Arduino** y un módulo **Bluetooth HC-05**.
